# 🔥 FireRoll - 幸运抽奖系统

一个功能丰富的纯网页端抽奖应用，支持特效、音效和自定义设置。

## ✨ 特性

- 📋 **名单管理** - 支持文件上传或手动输入参与者名单
- 🎨 **主题定制** - #018eee主色调，支持自定义颜色
- 🎵 **音效支持** - 可上传背景音乐和中奖音效
- 🎊 **丰富特效** - 彩纸飘落、Emoji雨等视觉效果
- 💾 **本地存储** - 设置自动保存到浏览器localStorage
- 📊 **结果导出** - 支持CSV格式导出中奖结果
- ⚡ **现代技术栈** - React + TypeScript + Vite + Tailwind CSS

## 🚀 快速开始

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```

### 预览构建结果
```bash
npm run preview
```

## 📖 使用指南

1. **上传名单**
   - 点击"上传名单文件"按钮，选择.txt或.csv文件
   - 或点击"手动输入名单"直接输入参与者

2. **开始抽奖**
   - 点击"开始抽奖"按钮启动动画
   - 系统会随机选中幸运者

3. **自定义设置**
   - 点击右上角设置图标
   - 调整动画速度、音效、特效等选项
   - 设置会自动保存

4. **导出结果**
   - 抽奖完成后可点击"导出结果"
   - 生成包含中奖者和时间的CSV文件

## 🎮 功能说明

### 特效控制
- **彩纸特效** - 中奖时的彩纸飘落动画
- **Emoji雨** - 可自定义的表情符号掉落效果
- **动画速度** - 1-10级可调的滚动速度

### 音效设置
- 支持上传自定义背景音乐
- 支持上传中奖提示音
- 可随时开关音效

### 主题自定义
- 8种预设颜色方案
- 支持自定义任意颜色
- 实时预览效果

## 🛠 技术栈

- **React 18** - UI框架
- **TypeScript** - 类型安全
- **Vite** - 构建工具
- **Tailwind CSS** - 样式框架
- **Framer Motion** - 动画库
- **React Confetti** - 彩纸特效
